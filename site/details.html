How goli works

A tiny server on your machine answers http://go/… and redirects you. Your links live in one YAML file you own. Everything below is the whole story — no account, no cloud.

The idea

When you type go/claude, your computer looks up the name go. goli adds one line to /etc/hosts so that name means “this machine”. The browser then asks goli's server for /claude; goli finds claude in your links file and replies “go to claude.ai”. That's it — a phone-book lookup and a redirect.

Big tech companies have had this for years (it started at Google). goli brings it to one person, with a few new tricks: search by meaning, links that depend on context, and a links file you can keep in git.

Install

macOS

  1. Build and install (needs Go 1.25+): 
    git clone https://github.com/chetanparab/goli && cd goli
make install
  2. Map go to this machine. goli hosts prints a single sudo tee command to run — goli never asks to run itself as root.
  3. Start it at login with goli install, then check everything with goli doctor.
  4. Open http://go/ once in your browser. After that, plain go/claude works in Chrome, Edge and Firefox.

Linux

Same build, then let goli use port 80 and run it as a user service:

sudo setcap cap_net_bind_service=+ep $(which goli)
systemctl --user enable --now goli   # unit file in the README

Why port 80? Browsers ask for http://go/ on port 80. goli listens there but answers only this machine (and devices you explicitly allow) — everyone else on your Wi-Fi gets a polite 403.

Your links

One file, ~/.config/goli/links.yaml. Short form or full form, mixed freely:

claude: https://claude.ai                       # short form
roadmap:                                        # full form
  url: https://docs.example.com/roadmap
  desc: Product roadmap and quarterly plans     # helps search
  tags: [planning, docs]
jira: https://acme.atlassian.net/browse/{1}     # go/jira/ABC-123
gh: https://github.com/me                       # go/gh/repo/issues appends the path
dashboard:                                      # context-aware
  url: https://grafana.example.com/d/prod
  variants:
    - when: {env: staging}
      url: https://grafana.example.com/d/staging
FeatureHow
Parameters{1}, {name}, {*} — each is escaped for where it sits (host, path or query).
Extra pathNo placeholders? Extra segments are appended: go/gh/goli/pulls.
Contextgoli ctx set env=staging, or per link: network, hours ("22-07"), days ("mon-fri").
Links as codePoint links_file at a git checkout. goli reloads on change, so git pull deploys.
Dead linksgoli check visits every link (it won't touch private network addresses unless you pass -local).

AI search & privacy

AI search is off until you turn it on. Without it, goli's local fuzzy search already handles typos and keywords — nothing leaves your machine.

Turn it on and go/?the doc with our q3 plans asks Claude which of your links you mean. Pick the engine:

EngineUses
claude-codeThe Claude Code CLI you're already signed in to (your Claude subscription). No API key. goli runs it with no tools, no plugins and no saved history.
anthropicThe Claude API, billed per request.

Exactly what is sent, and only when you search: your query, plus each link's name, description, tags and host name (for example docs.example.com, not the full address). You can send full URLs or none with send_urls. Opening a link never calls AI. If another website tries to trigger a search behind your back, goli answers with local search instead.

On your phone

Phones can't edit /etc/hosts, so goli uses Tailscale (free for personal use) — a private network between your own devices. Name your computer go in Tailscale, add allow: [tailscale] to goli's config, and your phone reaches http://go/ from anywhere.

On iPhone, Safari searches anything without a dot, so add http://go/ to your Home Screen: tap the go/ icon, type claude, done. Other devices can open and search links but not change them, unless you set allow_write: true.

From the terminal

goli claude                 # open a link (no server needed)
goli find cloudflare dash   # search
goli add docs https://docs.example.com -d "Team docs" -t work
goli ls · goli rm · goli edit · goli check · goli doctor

Security

goli had a full security and code review before going open source. In short:

  • Answers only this machine, plus networks you list — and only when the connection arrives on that network.
  • Blocks DNS rebinding (strict Host check), cross-site writes (Go's CrossOriginProtection) and clickjacking (frame-ancestors 'none').
  • Destinations must be http(s); every expanded URL is re-validated.
  • Logs record which link you opened, not where it points. Files are private to your user.
  • Releases are built in CI with pinned actions, a vulnerability scan and signed build provenance.

Found something? Please report it privately — see SECURITY.md.

FAQ

Will it clash with my company's go/ links?

On a work laptop where go already points to a company server, goli's hosts entry would take over. Use a different name there — goli works with any hostname you list in hostnames.

Does it work when my computer is asleep?

Your computer has to be awake to answer. On macOS, keep_awake: true prevents idle sleep while it's plugged in.

Windows?

Not yet. macOS and Linux are supported today; contributions welcome.

Why “goli”?

Go links → goli. And yes, the Hindi pun (goli dena — to give someone the slip) is fully intended: goli gets you past long URLs.
