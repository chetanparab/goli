How it works  ·  the whole story

A phone book and a redirect.

A tiny server on your machine answers http://go/… and sends you on. Your links live in one file you own. No account, no cloud — everything below is all there is.

i.

The idea

When you type go/standup, your computer first looks up the name go. goli adds one line to /etc/hosts so that name means “this machine”. Your browser then asks goli for /standup; goli finds standup in your links file and answers “go to meet.google.com/abc-defg-hij”. A phone-book lookup, then a redirect.

Big tech companies have run internal go links for years — it started at Google. goli brings the idea to one person, with a few tricks of its own: forgiving typos, search by meaning, links that depend on context, and a links file you can keep in git.

ii.

Install

macOS

  1. Install goli (needs Go 1.25+), or download a binary from the latest release. 
    $ go install github.com/chetanparab/goli/cmd/goli@latest
  2. Map go to this machine: goli hosts prints a single sudo tee command to run. goli never asks to run itself as root.
  3. Start it at login with goli install, then check everything with goli doctor.
  4. Open http://go/ once. After that, plain go/standup works in Chrome, Edge and Firefox.

Windows

  1. Download goli for Windows (or go install as above), unzip it and put goli.exe in a folder on your PATH.
  2. Run goli hosts. It prints one PowerShell command — run it in PowerShell opened with Run as administrator.
  3. goli install starts goli now and at every sign-in, with no console window and no admin rights. Check with goli doctor.

On Windows goli listens on 127.0.0.1 by default, so Windows Firewall never asks. Settings live in %AppData%\goli.

Linux

Same install. Let goli use port 80 once; then goli install sets up a systemd user service:

$ sudo setcap cap_net_bind_service=+ep $(which goli)
$ goli install

Why port 80? Browsers ask for http://go/ on port 80. goli listens there but answers only this machine — and devices you explicitly allow. Everyone else on your Wi-Fi gets a polite “no”.

iii.

Your links

One file, ~/.config/goli/links.yaml. Short form or full form, mixed freely:

standup: https://meet.google.com/abc-defg-hij          # short form
budget:                                                # full form
  url: https://docs.google.com/spreadsheets/d/1xQ7…/edit
  desc: Household budget, updated monthly              # helps search
  tags: [home, money]
pr: https://github.com/acme/app/pull/{1}               # go/pr/482
flight: https://www.flightradar24.com/data/flights/{1} # go/flight/6E-2134
gh: https://github.com/acme                            # + extra path
dashboard:                                             # context-aware
  url: https://grafana.acme.in/d/prod
  variants:
    - when: {env: staging}
      url: https://grafana.acme.in/d/staging
FeatureHow
Parameters{1}, {name}, {*} — each escaped for where it sits (host, path or query).
Extra pathNo placeholders? Extra segments are appended: go/gh/app/pulls.
Contextgoli ctx set env=staging, or per link: network, hours ("22-07"), days ("mon-fri").
Links as codePoint links_file at a git checkout. goli reloads on change, so git pull deploys.
Dead linksgoli check visits every link — but never private network addresses unless you pass -local.
iv.

AI search & privacy

AI search is off until you turn it on. Without it, goli's local fuzzy search already handles typos and keywords, and nothing leaves your machine.

Turn it on and go/?the doc with the wedding venues asks Claude which of your links you mean. Pick an engine:

EngineUses
claude-codeThe Claude Code CLI you're already signed in to — your Claude subscription, no API key. goli runs it with no tools, no plugins and no saved history.
anthropicThe Claude API, billed per request.

Exactly what is sent, and only when you search: your query, plus each link's name, description, tags and host name (say, docs.google.com — not the full address). Send full URLs or none with send_urls. Opening a link never calls AI, and if another website tries to trigger a search behind your back, goli quietly falls back to local search.

v.

On your phone

Phones can't edit /etc/hosts, so goli uses Tailscale — a free, private network between your own devices. Name your computer go in Tailscale, add allow: [tailscale] to goli's config, and your phone reaches http://go/ from anywhere.

On iPhone, Safari searches anything without a dot — so add http://go/ to your Home Screen instead: tap the go/ icon, type standup, done. On Android, open http://go/ in Chrome, then ⋮ → Add to Home screen.

Managing links from your phone

Add allow_write: true to goli's config and run goli restart. The Home Screen app then shows + New link, every link gets edit and × buttons, and a name that doesn't exist yet can be created from its own page. Leave it off if anyone else shares your Tailscale network: by default other devices can open and search links, but not change them.

vi.

From the terminal

$ goli standup                # open a link — no server needed
$ goli find budget            # search
$ goli add itr https://www.incometax.gov.in -d "Income tax e-filing" -t tax
$ goli ls · goli rm · goli edit · goli check · goli doctor
vii.

Security

goli had a full security and code review before it went open source. In short:

  • It answers only this machine, plus networks you list — and only when the connection really arrives on that network.
  • It blocks DNS rebinding (a strict Host check), cross-site writes (Go's CrossOriginProtection) and clickjacking.
  • Destinations must be http(s), and every expanded URL is checked again before you're sent there.
  • Logs record which link you opened, not where it points. Your files are readable only by you.
  • Releases are built in CI with pinned dependencies, a vulnerability scan and signed build provenance.

Found something? Please report it privately — see SECURITY.md.

viii.

Questions

Will it clash with my company's go/ links?

On a work laptop where go already points to a company server, goli's hosts entry would take over. Use another name there — goli answers to any hostname you list in hostnames.

Does it work while my computer sleeps?

Your computer has to be awake to answer. keep_awake: true stops idle sleep while goli runs (on a Mac, while it's plugged in).

Does it work on Windows?

Yes — macOS, Windows and Linux, on Intel and ARM. Phones (iPhone and Android) connect through Tailscale.

Why “goli”?

Go links → goli. And yes, the Hindi pun is intended: goli dena means giving someone the slip — goli gets you past long URLs.
