goli gives you the short links big companies use internally, on your own laptop. Name any page once, then reach it from the address bar, your terminal, or your phone. Forgot the name? Just describe it. Goli dena optional.

Get goli on GitHub → How it works

MIT licensed · macOS & Linux · one small Go binary

go/claude→claude.ai
go/gh/goli/issues→github.com/…/goli/issues — extra path just works
go/jira/ABC-123→your ticket, via a {1} template
go/roadmp→“did you mean go/roadmap?” + one-click create
go/?q3 planning doc→the right link, found by meaning (opt-in AI)
go/dashboard→staging or prod, depending on your context
Why goli

Bookmarks you can type

Like a dabbawala who knows every tiffin by its code: you say the short name, goli delivers the right page. No folders to dig through, no long URLs to remember.

🧭

Smart fallback

Typos show the closest matches. Unknown names get a form to create the link right there.

💬

Search by meaning

Opt in, and go/?words asks Claude which link you mean, then jumps there when it's sure.

🔀

Context-aware

One name, different places: dev or prod, home or office, weekday or weekend.

📄

Links as code

One readable YAML file. Keep it in git, review changes, and catch dead links with goli check.

⌨️

Terminal & phone

goli claude from the shell, a Raycast command, and a Home Screen app over Tailscale.

🔒

Private by default

Answers only your own devices. No account, no cloud, no tracking. AI is off until you turn it on.

Get started

Up and running in a minute

git clone https://github.com/chetanparab/goli && cd goli
make install     # builds and installs goli to ~/.local/bin
goli hosts       # prints the one sudo command that maps go → this machine
goli install     # starts the server at login (macOS)

Then open http://go/ once, add your first link with goli add claude https://claude.ai, and you're set. Linux, phones and AI search are covered on the details page.
