Add goli to your iPhone or Android Home Screen and it works like an app: tap go/, type standup, tap Go.

Your phone reaches goli on your computer through Tailscale, a free private network between your own devices — at home, at work or on mobile data. Add, edit and delete links from the phone too.

Nothing is uploaded to anyone's cloud: the phone talks to your own computer.

ii.

And in your terminal

$ goli standup        # opens it in your browser
https://meet.google.com/abc-defg-hij

$ goli add pr https://github.com/acme/app/pull/{1}
go/pr → https://github.com/acme/app/pull/{1}

$ goli find revenue
 85%  forecast             Revenue forecast sheet

Open, add, search and health-check links without leaving the keyboard. goli standup opens the link even when the server isn't running.

goli check visits every link and tells you which ones broke; goli doctor checks your whole setup.

iii.

Search by meaning, with the AI you already have

Forgot what you called a link? Type go/? and describe it. You choose what powers that search — and you can change your mind any time with goli ai setup or goli's settings page.

Off

Default

goli's built-in search forgives typos and matches descriptions. Nothing leaves your computer.

Claude Code

Your Claude subscription

Already signed in to Claude Code? goli uses that login — no API key, no separate bill.

Claude API key

A fraction of a cent per search

Paste a key from the Anthropic Console — free credits count. It's kept in your system keychain where available — never in config.yaml.

$ goli ai setup

Everyone connects their own account; goli never ships anyone's key. Only your query and your links' names, descriptions and site names are sent — and only when you search.

vi.

Small tool, careful details

  1. Typos forgiven

    A wrong name shows the closest matches, and a missing one can be created right there on the page.

  2. Search by meaning

    go/? plus a description finds the link you meant — powered by your Claude Code login or your own API key, or off entirely.

  3. One name, many places

    go/dashboard can open staging at work and prod on call — by environment, network or time of day.

  4. Links you can review

    Everything lives in one readable file. Keep it in git, review changes, and let goli check catch dead links.

  5. Everywhere you are

    Mac, Windows or Linux; the address bar, the terminal, Raycast — and your iPhone or Android phone.

  6. Built to be trusted

    Security-reviewed, strict by default, and every release is built in the open with signed provenance you can verify.

viii.

Yours, entirely

Your links live in one file, on your computer. No sign-up, no sync service, no analytics — and AI stays off until you switch it on. Just the shortest way back to the pages that matter.

ix.

Up in a minute

  1. Install goli. Unzip it and put goli on your PATH (on a Mac, first run xattr -d com.apple.quarantine goli, since the download isn't notarized yet). Download for Mac (Apple silicon), Mac (Intel), Windows or Linux (all downloads) — or, with Go installed: 
    $ go install github.com/chetanparab/goli/cmd/goli@latest
  2. Point go/ at your computer. goli hosts prints the one command to run (Terminal on Mac and Linux, an Administrator PowerShell on Windows); goli install starts goli at login. 
    $ goli hosts
$ goli install
  3. Add your first link, then type go/standup in your browser. 
    $ goli add standup https://meet.google.com/abc-defg-hij
  4. Optional: turn on AI search with your Claude Code login or an API key. 
    $ goli ai setup

Phones, AI options and every setting are in how it works.
