iii.

Small tool, careful details

  1. Typos forgiven

    A wrong name shows the closest matches, and a missing one can be created right there on the page.

  2. Search by meaning

    Opt in, and go/? plus a description finds the link you meant, then opens it when it's sure.

  3. One name, many places

    go/dashboard can open staging at work and prod on call — by environment, network or time of day.

  4. Links you can review

    Everything lives in one readable file. Keep it in git, review changes, and let goli check catch dead links.

  5. Everywhere you are

    The address bar, the terminal, Raycast — and your phone, through a private Tailscale network.

  6. Nobody else's server

    No account, no cloud, no tracking. goli answers only your own devices, and AI stays off until you switch it on.

iv.

Yours, entirely

Your links live in one file, on your machine. No sign-up, no sync service, no analytics — just the shortest way back to the pages that matter.

v.

Up in a minute

$ git clone https://github.com/chetanparab/goli && cd goli
$ make install      # builds goli into ~/.local/bin
$ goli hosts        # prints one command that maps go → this machine
$ goli install      # starts goli at login
$ goli add standup https://meet.google.com/abc-defg-hij

Open http://go/ once, then type go/standup. Linux, phones and AI search are covered in how it works.
