iv.

What you'll see

v.

Small tool, careful details

  1. Typos forgiven

    A wrong name shows the closest matches, and a missing one can be created right there on the page.

  2. Search by meaning

    Opt in, and go/? plus a description finds the link you meant, then opens it when it's sure.

  3. One name, many places

    go/dashboard can open staging at work and prod on call — by environment, network or time of day.

  4. Links you can review

    Everything lives in one readable file. Keep it in git, review changes, and let goli check catch dead links.

  5. Everywhere you are

    The address bar, the terminal, Raycast — and your phone, through a private Tailscale network.

  6. Built to be trusted

    Security-reviewed before release, strict by default, and every release is built in the open with signed provenance you can verify.

vi.

Yours, entirely

Your links live in one file, on your machine. No sign-up, no sync service, no analytics — and AI stays off until you switch it on. Just the shortest way back to the pages that matter.

viii.

Up in a minute

  1. Install goli — with Go, or grab a prebuilt download. 
    $ go install github.com/chetanparab/goli/cmd/goli@latest
  2. Point go/ at your machine. goli hosts prints the one command to run; goli install starts goli at login. 
    $ goli hosts
$ goli install
  3. Add your first link, then type go/standup in your browser. 
    $ goli add standup https://meet.google.com/abc-defg-hij

Linux, phones and AI search are covered in how it works.
