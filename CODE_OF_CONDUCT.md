# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions focused on the work. Harassment or personal attacks aren't tolerated.

Report unacceptable behaviour privately to the maintainer through GitHub ([@chetanparab](https://github.com/chetanparab)). Reports are handled confidentially.
